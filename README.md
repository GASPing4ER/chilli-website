# Gostilnica Chilli — website

Modern, light-themed single-page website for **Gostilnica in pizzerija Chilli**, Trg Tonete Čufarja 3, Jesenice.

- Plain HTML/CSS/JS, no build step — open `index.html` or serve the folder.
- Full menu data lives in the `MENU` array in `index.html`; prices in EUR.
- Live "Odprto zdaj" status is computed from the opening hours in `HOURS` (Europe/Ljubljana).
- Photo slots (`.ph` elements) are styled placeholders — swap in real photos as `<img>` or CSS backgrounds.

Fonts load from Google Fonts (Bricolage Grotesque, Instrument Sans, Instrument Serif).
